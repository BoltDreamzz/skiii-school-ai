# Skiii School AI

An ultra-lightweight AI assistant built by Dreamzzskiii for computer science students. It helps you understand concepts, debug code, review algorithms, and get quick explanations without the fluff — just a simple script you can run and use immediately.


## Features
- Instant explanations of CS concepts (data structures, algorithms, OS, networks, etc.)
- Code debugging and improvement suggestions
- Quick quiz-style practice questions
- Clean, no-nonsense interface focused on learning


## ⚠️ Challenges

This app is only built for CLI (command line interface) only. You need prior coding experience to use this AI assistant.


## Getting Started

Clone the repo, run the simple script, and start asking questions. Designed to stay fast and focused so you spend more time learning and less time configuring.
